# 日线涨停事件与次日高开：因子挖掘记录

这是北京大学当代量化交易系统课程的因子挖掘项目，使用 `vnpy.alpha` 检验一个直观想法：

> 股票当天强势上涨并收盘封板后，第二天是否更容易高开？

由于当前只有日线数据，本项目用“当日涨幅、收盘价相对最高价、日内最低价”等信息构造涨停代理，并以 `次日开盘价 / 当日收盘价 - 1` 作为预测目标。

研究共进行两轮：第一轮生成10个候选，拆解封板、量能、趋势和首板结构；第二轮生成12个候选，检查涨幅阈值、封板阈值、可成交振幅和首板窗口。最终保留3个因子。

## 结论

三个候选在 train、valid、test 中都保持正向，且2008–2023各年度 RankIC 全部为正。表现最好的是严格收盘封板代理：封板越接近日内最高价，次日相对高开的信号越明显。首板和日内上涨强度也有预测效果，但没有显著超过严格封板条件。
